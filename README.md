**Spotify Music Analytics Dashboard | Power BI**

**Project Overview**

This project focuses on analyzing Spotify music streaming data using Microsoft Power BI. The interactive dashboard provides insights into popular songs, artists, albums, and music streaming trends.

**Project Objectives**

Analyze Spotify streaming performance.

Identify top-performing songs and artists.

Explore album-wise music streaming.

Understand music trends and popularity.

Present meaningful insights through interactive visualizations.

**Key Metrics (KPIs)**

Total Streams

Total Songs

Total Artists

Total Albums

Average Streams

Most Streamed Song

**Dashboard Insights**

Top 10 Most Streamed Songs

Top 10 Artists by Streams

Album-wise Streaming Analysis
